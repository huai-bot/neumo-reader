# 拟物阅读 · Neumo Reader

一个专注阅读的轻量桌面 Markdown / 纯文本阅读器，采用暖米白新拟物（Soft UI）界面。
基于 Tauri 2 + React 构建。

## 功能

- **Markdown 阅读**：GFM（表格、任务列表、删除线、自动链接）、KaTeX 数学公式、GitHub 风格提示块
  （`> [!NOTE]` 等）、可选的安全 HTML 渲染、代码块一键复制、相对路径图片。
- **纯文本阅读**：`.txt` `.log` `.json` `.yaml` 等任意文本文件；自动识别 UTF-8 / UTF-16 / GB18030 编码。
- **多段选择和批注**：在正文拖选一段，再按住 `Ctrl` 拖选其他位置；`Ctrl` 单击可加选一个词。浮动工具栏可以复制、划线、高亮或写注释，多段按正文顺序复制。点击已有标记可修改或删除；批注随文件保存在阅读器数据目录，不改动原文。
- **编辑原文**：点标题栏铅笔（`Ctrl+E`）在当前阅读位置编辑，选中文字后可直接定位到选区开头。`Ctrl+S` 保存，再按 `Ctrl+E` 从编辑处继续阅读。切换文件保留草稿和光标，关闭或退出前会询问是否放弃未保存的修改。保存保留原编码和主要换行格式；原文件另有改动时保留草稿，不覆盖磁盘版本。
- **文档内查找**：点击标题栏的放大镜，或按 `Ctrl+F` 搜索当前文档。匹配处在正文中高亮，`Enter` / `Shift+Enter` 跳到下一处 / 上一处，`Esc` 关闭。Markdown 按排版后的正文查找，可跨粗体、链接等行内格式。
- **可收起侧边栏**：「文件」页管理已打开与最近文件，「大纲」页按标题跳转并高亮当前章节（`Ctrl+B`）。
- **字号调节**：标题栏 `− / +`、设置里的旋钮、`Ctrl + 滚轮`、`Ctrl+=` / `Ctrl+-` / `Ctrl+0`，调整时保持阅读位置。
- **恢复上次阅读**（设置中可开关）：未通过双击文件 / 命令行指定新文件启动时，自动重新打开上次退出时的文件，
  并回到当时的阅读位置；也可单独开关「记住每个文件的阅读位置」。
- **文件变化自动刷新**、拖拽打开、多文件标签、单实例（再次双击文件会在已打开的窗口中打开）、窗口大小位置记忆。
- 文档内相对链接（如 `[下一章](./chapter-2.md)`）会直接在阅读器中打开。

## 便携版

在软件所在文件夹放一个 `portable.flag` 文件即为便携模式：设置、最近文件、阅读位置、窗口大小位置以及 WebView2 缓存
都保存在同目录的 `data` 文件夹，不写入用户目录，可以连同文件夹一起拷走。
Releases 中的 `*_x64-portable.zip` 已经带好了这个文件，解压即用。

- 软件目录不可写时（如 `C:\Program Files`）会自动改用用户目录，并在启动时提示。
- 设置 → 数据 中可以看到当前模式和数据目录。
- 本地生成便携版：`npm run tauri build` 后运行 `npm run pack:portable`。

## 后台运行

点击关闭按钮时可以选择**收到托盘**（程序留在后台，悬浮层热键继续可用）或**直接退出**。第一次关闭时会询问并记住选择，之后可以在 设置 → 常规 中修改。

- 点击托盘图标：重新打开主窗口
- 软件运行时，按 `Ctrl+Alt+R` 可从其他程序、最小化或托盘返回主窗口。在 **设置 → 常规 → 显示主窗口** 点击当前组合键，再按下新组合即可修改；右侧开关可停用。
- 使用 `neumo-reader.exe --background` 可以启动到托盘，再用热键或托盘图标打开主窗口。
- 右键托盘图标：显示主窗口、显示 / 隐藏悬浮层、退出

## 悬浮层（游戏中看攻略）

在游戏里随时看攻略：悬浮层置顶显示，**不抢焦点、鼠标可穿透**，按热键呼出，不会打断游戏。

以下是默认热键，全部可以在 设置 → 悬浮层热键 中修改（点击后按下新的组合键），也可以用每项右侧的开关停用；关闭后会保留原组合键。

支持菜单键单独使用，或按住菜单键再按其他键，例如菜单键 + ↓。小键盘按物理位置识别，数字锁定开关不会影响已设置的热键；小键盘 2 / ↓ 和独立方向键 ↓ 可以分别设置。

| 热键 | 作用 |
|---|---|
| 按住 `` Alt+` `` | 偷看，松开即隐藏 |
| 轻按 `` Alt+` `` | 固定显示 / 取消固定 |
| `Alt+↑` / `Alt+↓` | 滚动（按住连续滚动） |
| `Alt+PgUp` / `Alt+PgDn` | 翻页 |
| `Alt+[` / `Alt+]` | 上一节 / 下一节（卡片模式下为上一步 / 下一步） |
| `Alt+\` | 切换步骤卡片 / 全文 |
| `` Alt+Shift+` `` | 调整模式：用鼠标拖动标题栏移动、拖右下角缩放 |

- **步骤卡片**（默认）：一次只显示一节或一步。有序列表和任务列表的每一项会拆成单独的卡片，列表前的说明放在第一步；也可以在设置里改成按章节拆分。按住偷看超过 1 秒、松开后，下次偷看会直接显示下一步（可在设置中关闭）。
- 悬浮层显示主窗口当前的文件，并从主窗口的阅读位置开始；在悬浮层里翻到哪，主窗口也会跟过去。
- 滚动、翻页、换节热键只在悬浮层显示时生效，平时不占用这些按键。
- 设置 → 悬浮层 中可以用旋钮调整背景不透明度（0–100%，文字始终不透明），以及背景模糊和字号。
- 透明背景下文字使用无模糊的细描边；背景不透明度低于 50% 时，自动使用浅色文字配深色描边，方便在明暗游戏画面上阅读。
- 适用于无边框 / 窗口化全屏的游戏。独占全屏的游戏上任何窗口都无法覆盖，请在游戏里改成无边框窗口。

## 开发

需要 Node.js 20+、Rust（stable）以及 Tauri 2 的系统依赖。

```bash
npm install
npm run tauri dev      # 开发调试
npm run tauri build    # 打包（Windows 输出 NSIS 安装包）
```

## 发布新版本

推送 `v*.*.*` 格式的 tag 时，GitHub Actions 会构建 Windows 安装版和便携版并发布到 Releases。
工作流只在推送 tag 时运行，没有定时任务，普通 push 和 PR 都不会触发。

```bash
npm run version:set -- 0.1.1        # 同步修改 package.json / tauri.conf.json / Cargo.toml 等文件的版本号
git commit -am "release: v0.1.1"
git tag v0.1.1
git push && git push origin v0.1.1  # 推送 tag 后开始自动构建
```

如果 tag 和文件里的版本号不一致，工作流会在第一步报错并停止，不会继续构建。
也可以不用 Actions，在本地运行 `npm run tauri build` 后用 `gh release create` 手动上传安装包。

## 设计规范（Soft UI）

| 项 | 值 |
| --- | --- |
| 底色 | `#F2E8E0`，卡片 / 按钮与底色同色，仅靠阴影成形 |
| 凸起 | `-6px -6px 14px #FFFFFF, 6px 6px 14px #D6C8BD` |
| 凹陷 | `inset 4px 4px 10px #D6C8BD, inset -4px -4px 10px #FFFFFF` |
| 圆角 | 卡片 24px，按键 16px，旋钮 / 指示灯正圆 |
| 强调色 | 钴蓝 `#2F4BD0`：仅用于按下、开启、当前项与关键数据 |
| 告警 | 朱橙 `#E2552D`，少量使用 |
| 文字 | 主 `#23201D`，次 `#6E655E`；几何无衬线 Outfit，数字用等宽 JetBrains Mono |
| 动效 | 弹簧曲线 `cubic-bezier(.34,1.56,.64,1)`，120–300ms |

拟物效果只用于可交互元素，正文与表格保持平整。设计变量集中在 `src/styles/neu.css` 顶部。
