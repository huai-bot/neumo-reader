拟物阅读 · 便携版
==================

使用方法
- 解压到任意可写的文件夹（例如 D:\Tools\拟物阅读），运行 neumo-reader.exe。
- 不需要安装。设置、最近文件、阅读位置和窗口大小位置都保存在同目录的 data 文件夹，
  连同整个文件夹一起拷走即可在其他电脑上继续阅读。
- 如果放在不可写的位置（例如 C:\Program Files），会自动改用用户目录保存，并在启动时提示。

文件说明
- neumo-reader.exe     主程序
- portable.flag         便携模式标记。删除它，软件就改为把数据保存在用户目录
- data\                 首次运行后自动生成，存放设置与阅读记录（可删除以重置）

注意
- 需要系统自带的 Microsoft Edge WebView2 运行时（Windows 10/11 一般已预装）。
- 便携版和安装版同一时间只能运行一个，后打开的会把文件交给已经打开的窗口。
- 便携版不会注册文件关联，可以把 .md 文件拖到 neumo-reader.exe 或窗口里打开。

项目主页：https://github.com/huai-bot/neumo-reader
